# OriForaginHelperMod

## ⚠️ Branch Guide

This repository has **two active development branches** for the core navigation rewrite:

| Branch | AI | Status | Description |
|--------|----|--------|-------------|
| `master` | 🟦 Gemini | M1 ✅ M2 ✅ | Gemini-driven implementation — continue here to pick up M3+ with Gemini |
| `claude-branch` | 🟧 Claude | M1 ✅ M2 ✅ | Claude-driven implementation — continue here to pick up M3+ with Claude |

Both branches start from the same M1+M2 foundation (RotationEngine + Pathfinder).
Pick the branch that matches the AI you want to continue with.
